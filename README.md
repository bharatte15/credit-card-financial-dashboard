# Credit Card Financial Dashboard (Power BI & Tableau)

An end-to-end analytics project that turns credit card customer data into dashboards covering **spending behaviour, credit utilization vs forecast, payment patterns and credit risk**, with a recommendation layer for business strategy.

> **Data note:** the dataset in this repo is **synthetic**, generated by `scripts/generate_credit_card_data.py`. It deliberately includes real-world data-quality problems (blanks, inconsistent labels, duplicates, sign errors) so the cleaning workflow is demonstrated end to end. All figures below come from this sample data, not from real customers.

---

## Business Questions

1. How is customer spending distributed across categories (travel, groceries, utilities, etc.)?
2. How does actual credit usage compare with forecasted usage?
3. What do payment patterns look like (on-time vs late vs unpaid)?
4. Which customers show credit-risk signals (high utilization and late payments)?

## Data Model

Star schema: `Dim_Customer` and `Dim_Date` filter `Fact_Transactions` and `Fact_Statements` (one-to-many, single direction).

| Table | Grain | Key fields |
|---|---|---|
| Dim_Customer | 1 row per customer | Age_Group, Income_Band, Card_Type, Region, Credit_Limit |
| Fact_Transactions | 1 row per transaction | Category, Amount, Channel, Txn_Date |
| Fact_Statements | 1 row per customer-month | Actual_Spend, Forecast_Usage, Outstanding_Balance, Payment_Status, Days_Late |

## Data Preparation

- Standardized labels (gender, spending categories) and trimmed text
- Removed duplicate transactions; corrected negative-amount sign errors
- Handled missing values: median imputation for age/income (with an `Age_Imputed` flag), "Uncategorized" for missing categories so totals still reconcile
- Derived fields: Age_Group, Income_Band, Days_Late, Payment_Status (On-time / Late 1-30d / Delinquent 30d+ / Unpaid), Utilization %, Usage Variance, Risk Score and Risk Tier

**Risk score** = `100 × (0.4 × avg utilization (capped at 1) + 0.6 × late/unpaid rate)`. High ≥ 40, Medium ≥ 20, Low otherwise. The weights are a simple heuristic for demonstration, not a validated credit model.

## Dashboard Pages

1. **Executive Overview**: KPI cards, monthly spend trend, category mix
2. **Spending Behaviour**: category × card type / age group, channel mix, regional treemap
3. **Credit Usage vs Forecast**: actual vs forecast lines, utilization by card type, overspend table
4. **Payments & Credit Risk**: payment status by month, risk scatter (utilization vs late rate), customer drill-through

Full visual specs, M queries and all DAX measures are in [`docs/Implementation_Guide.md`](docs/Implementation_Guide.md).

## Sample Findings (synthetic data)

- Travel is the largest spend category, followed by Shopping and Groceries
- Portfolio utilization is about 7.5% of total limits; about 6.8% of statements exceed forecast usage
- About 19.8% of statements are paid late or not at all
- 160 of 2,000 customers fall in the High risk tier

## Recommendations

| Finding | Action | KPI |
|---|---|---|
| High-risk tier holds a disproportionate share of outstanding balance | Early-warning outreach at a utilization threshold; instalment conversion before delinquency | Delinquent Exposure %, High Risk % |
| Customers paying only the minimum due | Auto-pay incentives and interest-cost transparency | Min-Due-Only Rate % |
| Low-utilization, always-on-time customers | Limit increase and premium-upgrade campaigns | Utilization %, Spend per Customer |
| Top spend categories | Category cashback / co-branded merchant offers | Category Share % |
| Actual usage above forecast in some segments | Recalibrate forecast and limit policy by segment | Usage Variance % |

## How to Run

```bash
git clone https://github.com/bharatte15/credit-card-financial-dashboard.git
cd credit-card-financial-dashboard
pip install -r requirements.txt

python scripts/generate_credit_card_data.py   # writes data/raw/*.csv
python scripts/build_tableau_workbook.py      # writes data/processed + tableau/CreditCard_Dashboard.twbx
```

- **Tableau:** open `tableau/CreditCard_Dashboard.twbx` in Tableau Desktop.
- **Power BI:** load the three CSVs from `data/raw/`, then follow `docs/Implementation_Guide.md` (Power Query → model → measures → visuals).
- **Your own data:** replace the files in `data/raw/`, keeping the same column names (or edit the scripts).
